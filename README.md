# THL時間割ツール Webアプリ版 デプロイ手順

GitHub + Vercel + Upstash Redis で動かす、複数人共有対応のWebアプリ版です。

## 構成ファイル

```
リポジトリのルート/
├── index.html      … ツール本体（閲覧・編集の両モードを含む）
├── vercel.json     … URL設定（/edit を編集画面に割り当て）
└── api/
    └── data.js     … データ読み書きAPI（Vercelサーバーレス関数）
```

## 仕組み

- **URLで閲覧用と編集用が分かれます。**
  - 閲覧者用: `https://～.vercel.app/` … 時間割を見る・検索する専用。編集ボタン類は表示されません。
  - 編集者用: `https://～.vercel.app/edit` … これまでどおりのフル編集画面。
    （`https://～.vercel.app/?edit` でも編集画面に入れます。/edit が404になる場合は
    　vercel.json がリポジトリのルートに無いので、配置して再デプロイしてください）
- データ（前期の編集・後期・学生別）は Upstash Redis に1つのレコードとして保存されます。
- **閲覧は誰でも可能**（URLを知っていれば見られます）。ただし**学生別の時間割は公開されません**（下記）。
- **学生別タブの扱い**：
  - 通常の閲覧URLでは学生別タブは表示されず、学生データはサーバーからも送られません。
  - 学生ごとに発行される**個別URL**（`https://～.vercel.app/?s=学生キー`）で開くと、
    **本人の時間割だけ**が表示されます（他の学生の情報は取得できません）。
  - 学生キーは編集画面で自動発行されます。編集画面の学生別タブにある
    「**学生URL一覧**」ボタンで、全員分のURLをテキストファイルに書き出せるので、
    各学生に本人のURLを1回だけ渡してください（時間割を更新してもURLは変わりません）。
  - 編集画面（/edit）は、学生データを含む全データを扱うため、**開いたときに編集パスワードの入力**が必要です。
- **編集の保存には「編集パスワード」が必要**です。編集して最初の保存時に入力を求められ、
  ブラウザを閉じるまで記憶されます。パスワードは Vercel の環境変数 `EDIT_TOKEN` で設定します。
- **同時編集の競合**：2人が同時に編集した場合、先に保存した人が優先されます。
  後から保存した人には「他の人が先に更新しました」と表示され、最新データが読み込み直されます
  （その人の直前の変更は保存されません）。編集する時間帯を分ける運用をおすすめします。
- サーバーに接続できない場合（PCでファイルを直接開いた場合など）は、
  従来どおりその端末内（localStorage）だけで動きます。

## 年度管理（前期・後期を年度ごとに運用）

- ヘッダーに現在の**年度**（例：2026年度）が表示されます。前期・後期・学生別は、その年度のデータとしてサーバーに保存されます。
- 編集画面のツールバーにある「**年度メニュー**」から、次の操作ができます。
  - **年度データをJSON書き出し**：前期・後期・学生別をまとめて1つのJSONに保存（バックアップ）。
  - **前年度をコピーして新年度**：今年度を土台に翌年度を作成。クラス時間割（前期・後期）は引き継がれ、学生別の個別時間割は空になります。
  - **空の新年度を作成**：前期・後期・学生別をすべて空にして翌年度を開始。
  - **年度データを読み込む**：書き出したJSONから、その年度の状態に復元。
- **年度の切り替えは元に戻せません。** 新年度を作成する前に、必ず「JSON書き出し」で今年度をバックアップしてください（学校の共有ドライブ等に保管）。
- 前期のクラス時間割は、サーバー管理になりました（以前の埋め込みデータは初期値としてのみ使われ、以降は編集内容がサーバーに保存されます）。

## デプロイ手順

### 1. GitHubにリポジトリを作る

1. GitHubで新しいリポジトリを作成（例: `thl-timetable`、Privateで可）
2. このフォルダの `index.html` と `api/data.js` をアップロード
   （Web画面なら「Add file → Upload files」でフォルダごとドラッグ）

### 2. Vercelにデプロイ

1. https://vercel.com にGitHubアカウントでログイン
2. 「Add New → Project」→ 作ったリポジトリを Import
3. 設定はそのままで「Deploy」
   （Framework Preset は Other / 自動検出のままでOK）

### 3. データベース（Upstash Redis）をつなぐ

1. Vercelのプロジェクト画面 → **Storage** タブ
2. **Marketplace** から **Upstash**（Redis）を選び、Create → プロジェクトに Connect
3. 接続すると `KV_REST_API_URL` / `KV_REST_API_TOKEN`（または
   `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`）が
   環境変数として自動追加されます（どちらの名前でも動きます）

### 4. 編集パスワードを設定

1. プロジェクトの **Settings → Environment Variables**
2. Name: `EDIT_TOKEN` ／ Value: 好きなパスワード（例: `thl2026`）を追加
3. 環境変数を追加・変更したら **Deployments から Redeploy**（再デプロイで反映）

### 5. 完成

- **閲覧する人**には `https://～.vercel.app/` を共有します。
  PCでもスマホでも、開くだけで最新の時間割を見る・検索できます。
- **編集する人**は `https://～.vercel.app/edit` を開きます。
  変更すると自動でサーバーに保存されます（初回保存時に編集パスワードを入力）。
- ヘッダーの「**最新に更新**」ボタンで、他の人の変更を読み込めます。

## 運用のポイント

- **初回**：デプロイ直後はサーバーにデータが無いので、編集担当者がツール上で
  データを入れる（またはJSON読込する）と、それがサーバーに保存されます。
- **編集パスワードの共有**は編集する人だけに。閲覧する人にはトップのURLだけ伝えれば十分です。
- `/edit` のURL自体は隠していないため、閲覧者が知る可能性はありますが、
  **編集パスワードが無ければサーバーのデータは変更できません**（画面上で操作しても保存されません）。
- 以前あった「閲覧版を書き出す」機能は、Webアプリ化に伴い廃止しました
  （閲覧者はトップURLを開くだけでよいため不要になりました）。
- PCでHTMLファイルを直接開いた場合（file://）は、従来どおり編集画面として
  端末内（localStorage）だけで動きます。
- **パスワードを変えたいとき**は `EDIT_TOKEN` を変更して Redeploy。
- URLを知っていれば誰でも閲覧できます。学内限定にしたい場合は、
  Vercelの有料機能（パスワード保護）や、URLを学内でのみ共有する運用で対応してください。

## PWA（ホーム画面に追加してアプリのように使う）について

このツールはPWA対応です。スマホでURLを開き「ホーム画面に追加」すると、アプリのように全画面で起動できます。

### ファイル構成（PWA関連）

リポジトリ直下に以下を配置します（api/ フォルダの外）。

- index.html … 閲覧用（トップ）
- edit.html … 編集用（/edit でこれが表示される）
- student.html … 学生URL（?s=）・ワールドURL（?w=）用
- manifest.json … 閲覧アプリの定義（深緑アイコン「THL時間割」）
- manifest-edit.json … 編集アプリの定義（紫アイコン「THL編集」）
- sw.js … オフライン対応・高速起動（常にネット優先で更新は必ず届く）
- アイコン各種（icon-*.png / icon-edit-*.png / apple-touch-icon*.png）
- vercel.json … URLの振り分け（下記）

### vercel.json の役割

- `/edit` → edit.html（編集アプリとして独立。紫アイコンで別アプリになる）
- `?s=` または `?w=` 付き → student.html（manifestを持たないため、iOSでURLがそのままホーム画面に登録される）
- それ以外 → index.html（閲覧アプリ）

### 更新（差し替え）時の注意

- 機能を修正したときは、**index.html・edit.html・student.html の3つを必ずセットで差し替え**てください（中身のプログラムは共通。バージョン表記も3つ揃えます）。
- アイコンやアプリ名を変えた場合、すでにインストール済みのスマホには自動反映されません。一度アプリを削除して、追加し直すと新しくなります。
- スマホでの確認は、iPhoneはSafari→共有→「ホーム画面に追加」、AndroidはChromeの「アプリをインストール」から。編集は /edit を、学生は個別URLを、それぞれ追加します。
